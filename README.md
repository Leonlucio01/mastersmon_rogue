# Mastersmon Rogue

Base inicial de un RPG 2.5D con React, React Three Fiber, Express, Prisma y PostgreSQL.

## Estructura

- `client/`: interfaz del juego, escena 3D, HUD, inventario y combate.
- `server/`: API REST con datos mock y esquema inicial de Prisma.

La API usa mocks por defecto para poder levantar el juego antes de configurar la base de datos.

## Requisitos

- Node.js LTS (20.19+ o 22.12+)
- PostgreSQL local en el puerto `5432`

Los pasos de instalación y ejecución están documentados en la entrega del proyecto.
